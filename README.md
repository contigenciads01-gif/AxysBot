# AxysBot

Painel de automacoes inteligentes para contas de redes sociais (X/Twitter).

Stack: Next.js (App Router) + Tailwind CSS v4 + Inter. Deploy em Vercel.

## Estrutura

- `painel-redesign.html` - prototipo do novo painel: tema azul com fundos Branco/Bege/Escuro, densidade Compacto/Amplo, layout responsivo e dashboard ao vivo (acoes por minuto, acoes por tipo, latencia dos proxies, uptime 24h).
